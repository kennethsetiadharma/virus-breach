# Virus Breach — CMPT276 Group 15

## Requirements

- Java 21
- Maven 3.8+

## Build

```shell
mvn compile
```

## Run

```shell
mvn javafx:run
```

## Test

```shell
mvn test
```

## Test Coverage Report

```shell
mvn test jacoco:report
```

After running, open `target/site/jacoco/index.html` in a browser to view the full line and branch coverage report.
